# デモアドイン ― 作成・配布ガイド

選択したセルに「こんにちは！」と入力するだけの、練習用Excelアドインです。
このガイドどおりに進めれば、友人・同僚に渡せるところまで完成します。

---

## 📁 入っているファイル

| ファイル | 役割 |
|---|---|
| `index.html` | ボタンなどの画面本体（Excelの右側に出るパネル） |
| `manifest.xml` | Excelにアドインを認識させる設定ファイル。**これを人に配ります** |
| `icon-32.png` / `icon-80.png` | リボンに表示されるアイコン |
| `README.md` | このファイル |

---

## 🌐 なぜ「公開」が必要？

VBAマクロと違い、Officeアドインは **HTMLファイルをインターネット上に置き、
Excelがそこを読みに行く** 仕組みです。
そのため、まず `index.html` などを無料のWebホスティング（GitHub Pages）に
公開する必要があります。公開は無料で、5〜10分ほどで終わります。

---

## 🚀 手順1：GitHub Pages で公開する

1. [https://github.com](https://github.com) でアカウントを作る（無料）
2. 「New repository」で新しいリポジトリを作成
   - リポジトリ名は **`excel-demo-addin`** にする（manifestのURLと揃えるため）
   - 「Public」を選択
3. 作成後の画面で「uploading an existing file」をクリックし、
   このフォルダの **`index.html` / `icon-32.png` / `icon-80.png`** をアップロード
   （`manifest.xml` はアップロード不要ですが、してもOK）
4. リポジトリの **Settings → Pages** を開く
5. 「Source」を **Deploy from a branch**、Branch を **main / (root)** にして Save
6. 数分待つと、次のURLで公開されます：
   ```
   https://（あなたのGitHubユーザー名）.github.io/excel-demo-addin/index.html
   ```
   ブラウザで開いて、緑色の画面が出れば成功です。

---

## ✏️ 手順2：manifest.xml のURLを書き換える

`manifest.xml` をテキストエディタ（メモ帳でOK）で開き、
**`YOUR-GITHUB-USERNAME`** を、あなたのGitHubユーザー名に**すべて**置き換えて保存します。

例：ユーザー名が `taro123` なら
`https://YOUR-GITHUB-USERNAME.github.io/...`
→ `https://taro123.github.io/...`

（全部で7か所あります。エディタの「置換」機能を使うと確実です）

---

## 💻 手順3：自分のExcelで試す（サイドロード）

Officeアドインは「共有フォルダ」経由でExcelに読み込みます。

1. PCのどこかに `manifests` というフォルダを作る（例：`C:\Share\manifests`）
2. その中に、書き換え済みの **`manifest.xml`** を入れる
3. フォルダを右クリック →「プロパティ」→「共有」タブ →「共有」→ 自分を追加して共有
   - 表示される **ネットワークパス**（例：`\\PC名\manifests`）をメモ
4. Excelを開く →「ファイル」→「オプション」→「トラスト センター」
   →「トラスト センターの設定」→「信頼できるアドイン カタログ」
5. 「カタログのURL」にメモしたパスを貼り付け →「カタログの追加」
   →「メニューに表示する」にチェック → OK
6. Excelを再起動
7. 「ホーム」タブ →「アドイン」→「共有フォルダー」→「デモアドイン」を選ぶ
8. リボンに「デモを開く」ボタンが出れば成功！押すとパネルが開きます

---

## 🎁 手順4：友人・同僚に渡す

渡すのは **書き換え済みの `manifest.xml` 1つだけ** です。
（HTML本体はGitHubに公開済みなので、相手のPCには不要）

相手には「手順3」と同じ操作をしてもらいます。
つまり、相手も自分のPCで共有フォルダを作り、そこに `manifest.xml` を置いて
Excelに登録する、という流れです。

> 💡 もっと簡単に配りたい場合は、Microsoft 365 の管理センター（組織のIT管理者向け）
> から「一元展開」する方法もあります。会社で配るならIT担当に相談すると楽です。

---

## ⚠️ よくあるつまずき

- **ボタンが出ない**：Excelの再起動を忘れていないか確認
- **パネルが真っ白**：GitHub PagesのURLが正しいか、ブラウザで直接開いて確認
- **公開直後に見えない**：GitHub Pagesは反映に数分かかることがあります
- **アイコンが表示されない**：icon画像がアップロードされているか確認

---

これは練習用の最小構成です。慣れてきたら、ボタンを増やしたり、
入力する文字を変えたりして拡張してみてください。
